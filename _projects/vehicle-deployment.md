Led vehicle-side perception model development across detection, segmentation, and occupancy for multiple automotive compute platforms.

The work combined model design, training, operator-level optimization, latency analysis, and high-quality C++ implementations for operators unsupported by target chips. These systems supported production-oriented highway and urban NOA programs.

**Focus:** efficient deep learning, automotive SoCs, C++ optimization, production model deployment.
